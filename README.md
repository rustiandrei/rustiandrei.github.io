# rustiandrei.github.io

The root of https://rustiandrei.github.io/

- `app-ads.txt`: the AdMob authorized-sellers file. AdMob reads it from the root of the domain set as the developer website in the App Store and Google Play listings, so it has to stay here. Don't move or rename it.
- `index.html`: a short list of the apps, linking to each app's own site (`/Widgetik-website/`, `/foldline/`), which are separate repos.
